# 视觉标识 / Visual identity

[项目首页](../../README.md) · [Wiki](../wiki/README.md)

墨控使用纸白与墨黑，三条像素带表示灰阶、量化与扫描。标识采用可编辑 SVG，应用入口使用相同图形的 Android VectorDrawable；不依赖在线字体、远程图片或生成服务。

InkControl uses paper white and ink black. Three pixel bands refer to grayscale, quantization, and scanning. Editable SVGs and the matching Android VectorDrawable share one mark; no remote fonts or image service are required.

| 文件 / File | 用途 / Use |
| --- | --- |
| `mark.svg` | 项目标识 / Project mark |
| `banner.svg` | README 横幅 / README banner |
| `../../res/drawable/ic_launcher.xml` | 应用入口图标 / Launcher icon |

The original artwork follows the project's MIT license. The mark does not certify panel quality, power consumption, or long-term stability.
