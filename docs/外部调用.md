# 从应用外面调用墨控

不用打开墨控：发一条广播过去，墨控自己把动作做完。刷格言由 SystemUI 换图，四个总开关直接改配置。
墨控被「强制停止」时广播叫不醒它，改用第三节的透明页。

## 一、能调什么

| 能力 | 参数 | 说明 |
| --- | --- | --- |
| 刷新格言 | `-a com.inkcontrol.action.REFRESH_MOTTO` | 让锁屏格言往前跳一条 |
| 遮挡息屏 | `-a com.inkcontrol.action.TOGGLE --es feature cover` | 遮挡息屏开关 |
| 锁屏主题 | `-a com.inkcontrol.action.TOGGLE --es feature lock` | 关闭即恢复原厂样式 |
| 自动刷新 | `-a com.inkcontrol.action.TOGGLE --es feature refresh` | 自动刷新总开关 |
| 翻页动画 | `-a com.inkcontrol.action.TOGGLE --es feature pageanim` | 翻页动画总开关 |
| 待机与联网 | `-a com.inkcontrol.action.IDLE --es policy always` | 三项待机设置，调参时不用进界面 |

四个开关的 `feature` 写别名或功能 id 都行：`cover` = `wave.lock`、`lock` = `lock.style`、
`refresh` = `refresh.master`、`pageanim` = `pageanim.master`。

默认**取反**（开着就关、关着就开）。要指定状态就加 `--ei value 1`（开）或 `--ei value 0`（关）。
只开放这四个总开关，细节参数（延时、分块、名单等）不对外暴露，免得脚本把配置改成半开状态。

**待机与联网**是唯一的例外，它本来就要调参数，所以单独给了一个 action，三个参数都可选、可一次给全：

| 参数 | 取值 | 对应界面项 |
| --- | --- | --- |
| `--es policy` | `always` / `charging` / `never` / `default` | WLAN 休眠策略（始终连接 / 仅充电保持 / 永不保持 / 系统默认） |
| `--es net` | `30` / `60` / `120` / `default`，或 1–999 的秒数 | 保网时长（30 秒 / 1 分钟 / 2 分钟 / 系统默认 / 自定义） |
| `--es sleep` | `3` / `10` / `30` / `default` | 浅睡待机（3 / 10 / 30 分钟 / 系统默认） |

`default` ＝「系统默认」：墨控把对应的设置项删掉，回到系统自带的值（本机是始终连接 / 1 分钟 / 3 分钟）。
`net` 也可以直接给秒数（如 `--es net 90`），和界面上「自定义」等价。
一次改多项只落盘一次、下发一次，不会出现改一半的状态。

## 二、广播（最省事，脚本 / 自动化首选）

```sh
# 换下一条格言
am broadcast -a com.inkcontrol.action.REFRESH_MOTTO -p com.inkcontrol

# 切换遮挡息屏
am broadcast -a com.inkcontrol.action.TOGGLE -p com.inkcontrol --es feature cover

# 明确打开自动刷新
am broadcast -a com.inkcontrol.action.TOGGLE -p com.inkcontrol --es feature refresh --ei value 1

# 待机与联网：WLAN 始终连接、保网 30 秒、浅睡 10 分钟
am broadcast -a com.inkcontrol.action.IDLE -p com.inkcontrol \
  --es policy always --es net 30 --es sleep 10

# 只把保网时长改回系统默认
am broadcast -a com.inkcontrol.action.IDLE -p com.inkcontrol --es net default
```

su shell、Termux、Tasker 的「发送广播」、MacroDroid 的「发送意图」都能用，不需要墨控在前台。
收到后立刻返回，没有界面。

`-p com.inkcontrol` 不能省：Android 8 起静态注册的接收器收不到**隐式**广播，不带包名会被
`BroadcastQueue` 拦成 `Background execution not allowed`，命令看起来成功了、动作却没发生。
带上包名算显式投递，才到得了 `MottoReceiver` / `ToggleReceiver`。

墨控进程**被系统回收**不影响这个入口：广播会把进程重新拉起来（实测 `kill -9` 之后仍然生效）。
只有**被「强制停止」**（`am force-stop`、系统设置里点「强行停止」、部分手机管家的深度清理）才会失效：
应用处于 stopped 状态，静态广播一律不投递。加 `--include-stopped-packages` 能让广播投递，
但本机（海信）的安全服务仍会把这次后台拉起拦掉，所以这种情况请改用第三节的透明页。

## 三、启动透明页（墨控被「强制停止」时用这三条）

```sh
am start -n com.inkcontrol/com.inkcontrol.ui.MottoActivity

am start -a com.inkcontrol.action.TOGGLE -n com.inkcontrol/com.inkcontrol.ui.ToggleActivity \
  --es feature cover

am start -n com.inkcontrol/com.inkcontrol.ui.IdleActivity \
  --es policy always --es net 30 --es sleep 10
```

三个页面都是透明、无历史、不占任务栈的空壳，做完自己 `finish()`，不会把墨控主界面拉起来。
厂商的进程管控只拦 provider / service 的拉起，不拦 `startActivity`，所以被 force-stop 之后
广播叫不醒它的时候，这三条仍然生效（和面板开关的 `PanelToggleActivity` 是同一套思路）。
参数和广播那套完全一样：`policy` / `net` / `sleep` 都可选、可一次给全。

## 四、链路

```
外部 am / 桌面快捷方式 / 面板按钮
   ├─ MottoReceiver（广播）或 MottoActivity（透明页）
   │    → MottoCommand.request()
   │    → sendBroadcast(LOCK_MOTTO_NEXT, package=com.android.systemui)
   │    → 锁屏 Hook → MottoHelper.getNextMotto()
   └─ ToggleReceiver（广播）或 ToggleActivity（透明页）
        → ToggleCommand.apply()
        → ApplicationServices.change() → 写配置 → root 下发
   └─ IdleReceiver（广播）或 IdleActivity（透明页）
        → IdleCommand.apply()
        → ApplicationServices.changeAll() → 一次写三项 → root 下发
```

开关走的是和界面同一条写入链路，因此环境检查照样生效：后端没就绪时不会「开关看着开了、实际没生效」。

## 五、前置条件与反馈

- 刷新格言需要 LSPosed 作用域含 `com.android.systemui`；否则广播发得出去、但没人换（也不报错）。
- 四个开关需要后端模块已装且 `sys.inkcontrol.ready=1`，否则会提示「请先完成安装和完整重启」。
- 待机与联网不查就绪状态：配置照写，但要真正落到系统设置里仍得有后端模块；没装后端时只改配置。
- 刚安装或刚升级墨控之后要先打开一次应用：`pm install` 会把包置回 stopped 状态，静态接收器不投递广播，
  这时用第三节的 `am start` 或手动开一下墨控即可恢复。
- 刷格言的反馈在 SystemUI：「已换到下一条格言：…」；开关的反馈是设备上一条 Toast：`已开启：…` / `已关闭：…`，
  失败时弹具体原因。

## 相关文件

| 文件 | 作用 |
| --- | --- |
| `src/com/inkcontrol/features/lock/MottoCommand.java` | 刷新格言的唯一出口，`ACTION` 与 `request()` |
| `src/com/inkcontrol/features/lock/MottoReceiver.java` | 格言的外部广播入口（manifest 注册，exported） |
| `src/com/inkcontrol/features/external/ToggleCommand.java` | 四个总开关的出口：别名解析、取反/指定值、后台执行 |
| `src/com/inkcontrol/features/external/ToggleReceiver.java` | 开关的外部广播入口（`goAsync`，处理完再放行） |
| `src/com/inkcontrol/features/external/IdleCommand.java` | 待机与联网三项的出口：参数白名单、批量改值、回一句结果 |
| `src/com/inkcontrol/features/external/IdleReceiver.java` | 待机与联网的广播入口 |
| `src/com/inkcontrol/features/external/ExternalTask.java` | 两个入口共用的「后台执行 + Toast + 放行」，失败原因同时写 logcat（tag `InkControl`） |
| `src/com/inkcontrol/ui/MottoActivity.java` / `ToggleActivity.java` / `IdleActivity.java` | 透明页入口；桌面快捷方式的「刷新格言」也戳前者 |
| `src/com/inkcontrol/features/lock/Hook.java` | SystemUI 侧真正干活的地方（`ACTION_MOTTO_NEXT`） |
