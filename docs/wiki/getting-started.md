# 安装与使用

[English](getting-started.en.md) · [Wiki](README.md)

## 适用环境

目标：**Hisense A5 Pro 经典版黑白屏**。当前后端检查 `ro.product.device=HLTE203T`、API 29、`arm64-v8a`、固件字段包含 `L1732.6.01.02`，并核对原厂库哈希。商品名相同不意味着可跳过这些门槛。需要 Magisk 与 Vector／兼容 Xposed 框架才能启用相应增强。

## 第一次安装

1. 从私有仓库 [Releases](https://github.com/wzp100/InkControl/releases) 下载带签名 APK，核对版本说明和 SHA256SUMS。`-unsigned` 文件不可安装，旧版产物不要混用。
2. 先备份现有配置、旧 APK 和模块；rc13 起为新发行签名，旧签名 App 需卸载后再安装。不要为了覆盖安装自行重新签名。
3. 进入 App“安装”页，检查环境与旧模块冲突，从该 APK 导出匹配的 Magisk ZIP 并安装。
4. 框架作用域：系统框架 `android`、系统界面 `com.android.systemui`、原厂桌面 `com.hmct.vision`。
5. 完整重启，确认安装页和诊断页回执。首次安装所有 52 个增强均为关闭，再按需逐项开启。

上述步骤需要设备操作授权；文档维护与 CI 不会代为执行。已安装的 GPU 修复候选不要被旧 rc10 APK 内置的早期后端覆盖。

## 日常使用

- 四个显示模式与视频场景分别选算法。选择只改量化方法，不切换应用的刷新模式。[算法与迟滞](algorithms.md)。
- 父项关闭会停止子项效果，同时保留子项选择。启动期功能提示重启；开关保存不等于已生效。
- 右上角语言选择支持跟随系统、简体中文和 English；不改功能配置，也不修改全局系统语言。
- 无 Root 时可读说明、看演示、选择语言、导出安装包；不能据此认为显示后端已运行。
- Google split 图标覆盖在当前固件未通过，保持关闭。实验项先读说明及验证边界。

升级时使用同一 Release 的 App 与后端；若出现异常，按[诊断与恢复](operations.md)先留证，再按模块的停用／卸载恢复入口处理。不要将“清晰全刷”与“局部更新”视为同一操作。
