# 术语表

[English](glossary.en.md) · [Wiki](README.md)

| 术语 | 在本项目中的含义 |
| --- | --- |
| HWC | 厂商 Hardware Composer；负责输入、模式、刷新处理及扫描消费 |
| GPU helper | `libeinkgpu.so`，匹配路径中的计算实现；加载不等于实际工作 |
| 模式 | 外部刷新请求及内部决策，例如清晰、阅读、快速、极速 |
| 量化／抖动 | 连续灰度转换为有限灰级或黑白像素；不等于波形 |
| Bayer | 固定空间阈值矩阵；黑白与16级灰使用各自实现 |
| 蓝噪声 | 固定噪声阈值纹理，分散量化误差的视觉结构 |
| 误差扩散 | 将当前量化误差传播到后续像素，存在空间依赖 |
| 点量化 nearest | 就近量化到16级灰，不向邻近像素扩散误差 |
| 迟滞 | 利用旧帧保持阈值附近的像素稳定；独立开关只支持部分黑白算法 |
| WBF／波形 | 按旧/新像素、温区与阶段决定面板驱动，不是屏幕截图 |
| 波次／扫描帧 | 一次更新所需的一组驱动计算／其中一次扫描，均不直接等于FPS |
| fence | GPU或缓冲区工作的同步点；等待时间与计算耗时需分开 |
| HOT／REBOOT | 热应用／需要完整重启的功能配置类型 |
| 修订号 revision | 单调增加的配置快照标识，用于匹配执行回执 |
| PID + starttime | 进程身份；防止仅用PID时把复用进程当成旧进程 |
| boot_id | 本次启动标识；防止旧启动回执被当成本次生效 |
| 条件恢复 | 只有当前值仍由模块拥有时才恢复原值 |
| CPU 回退 | 不支持或发生故障后由原厂CPU路径处理；慢不一定代表回退 |
| 独立核验证 | 固定输入比较计算结果；不访问面板或证明完整HWC集成 |
| 候选／预发布 | 开发版本；通过云端检查仍需有范围的设备验收 |
