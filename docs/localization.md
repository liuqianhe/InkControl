# 双语维护

[English](localization.en.md)

应用右上角“中 / EN”提供跟随系统、简体中文和 English。默认跟随系统；中文使用中文，其他系统语言回退英文。偏好保存在设备保护存储中，切换仅重建 Activity，不申请 Root，不改增强配置或全局进程 Locale。

原生应用名称和框架说明使用 `res/values` 英文资源、`values-zh` 中文资源，`locales_config.xml` 声明支持语言。既有纯代码 UI 通过 `assets/i18n/en.tsv` 完整短语表翻译标题、功能说明、术语、选项、状态、对话框、Toast、图表与无障碍说明。最长短语优先，避免复合文本中短词抢先替换；数字格式单独验证。原始等宽诊断输出保留原样，歌词、曲名等实际内容不做机器翻译。

功能目录和 Guide 的原始字符串继续作为稳定路由和判断值，翻译只发生在最终显示边界。没有把语言写入功能配置，也不翻译 ID、属性名或 Shell 控制协议。新增或修改文字后必须同步英文表；`tools/check_i18n.py` 检查来源覆盖、重复项和占位符；云端 `TextCatalogTest` 验证双向显示、组合标签、数字温度、未知内容及配置不变。

历史研究和原始设备日志保持原文，只保留在本地。第三方媒体、天气与日历内容保留来源语言；本轮不对用户内容进行自动翻译。上机前仍需核对两种语言下的实际排版与操作。
