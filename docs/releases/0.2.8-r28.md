# 墨控 InkControl 0.2.8-r28（versionCode 28）

## 更新内容

### 新增

- **四个总开关可从外部调用**：新增 `com.inkcontrol.action.TOGGLE`，脚本或自动化工具能直接开关遮挡息屏、锁屏主题、自动刷新、翻页动画，不用打开墨控。默认取反，也可指定开或关；用法见 `docs/外部调用.md`。
- **快捷设置页扩到 5 项**：面板上的「墨控快捷设置」进来后依次是遮挡息屏、锁屏主题、自动刷新、翻页动画、刷新格言，前四项带开关，格言那一行点了直接换下一条。
- **后台任务列表里不显示墨控**：墨控放到后台后，最近任务（后台任务）列表里不再出现它的卡片，避免误点、误清。想让它重新出现在列表里，去「模块设置 → 后台任务」把「隐藏」改成「显示」即可，改完立刻生效。
- **系统增强新增「待机与联网」**：「WLAN 休眠策略」对应系统设置里的「在休眠状态下保持 WLAN 网络连接」（始终连接 / 仅充电保持 / 永不保持，Android 10 已不执行这一项，由墨控自己关和开）；「保网时长」和「浅睡待机」控制息屏后多久断网、多久进入浅睡待机，保网时长还支持自定义秒数。三项都能选「系统默认」回到原厂值，也能用广播改，改完立即生效。

### 修复

- **翻页动画后残留白底**：微信读书墨水屏版里点开「注释」再关掉，偶尔会播一次刷新动画并在页面上留一块注释大小的白底，要再点一下屏幕或等一会才消失。现在只有整屏改动足够大（真正换页）才走分块揭示，弹窗开合、工具栏开关这类小面积更新按原速刷新。

### 变更

- 快捷设置页顶部那句「常用三项放在一页」的说明删掉，页底说明补上翻页动画。
- 外部调用文档 `docs/刷新格言外部调用.md` 改名为 `docs/外部调用.md`，补上四个开关的命令、别名对照与透明页写法。

## 使用注意

- 本版后端有变化：**安装包与后端模块版本号必须一致**，升级时同批重装并完整重启一次。
- 外部调用必须带包名（`-p com.inkcontrol`），否则 Android 8 起收不到这类广播；墨控被强制停止时改用透明页入口。
- 翻页动画的分带门槛可用 `setprop debug.inkcontrol.fusion.minpercent` 调整，默认 12，填 0 等于关掉门槛；某些书页翻页动画消失时把这个值往下调到 8 试试。
