# 墨控 InkControl 0.1.0-rc15

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布。本版本接续公开仓库与原生 Wiki，显示算法和默认设置保持不变。包含统一黑白图标与 README 视觉、双语 Wiki、Agent 接手与证据索引、云端验证后的自动 Release。保留分模式算法、视频独立选择、独立迟滞及现有默认配置；52 个增强全部默认关闭。

## 安装与验证范围

使用本 Release 的 APK；配套后端已内置，也提供同版本 ZIP。适配门槛：HLTE203T、API29、arm64、L1732.6.01.02 及准确原厂输入哈希。rc13 起的新签名不能覆盖旧签名 App；首次迁移先备份配置并卸载旧 App，再安装新版与匹配后端。

发布门槛：云端回归、原生/GPU 对照、App/Overlay 签名、包装校验、四组中英文界面检查。当前手机记录仍为 rc10 App + rc10-gpu-fix1；本次自动发布不安装或改动手机。真实 HWC 集成、面板、温区、功耗、长稳仍待独立验收。历史首 GPU 错误根因未确定；Google split 图标覆盖保持关闭。

SHA256SUMS 覆盖全部附件；构建清单与 release-verification.json 记录准确来源。中文与英文文档发布于 GitHub 原生 Wiki；docs/wiki 保留可审查、可离线阅读的维护源。公开前已清理提交邮箱，私钥与密码保留在本地和 Actions Secrets。旧私有发布不覆盖。
