# 墨控 InkControl 0.2.9-r29（versionCode 29）

## 更新内容

### 新增

- **锁屏主题「透明书封」**：用熄屏前那一屏做底，上面盖一张带透明通道的书封图；「01 样式」里书封相关的控制项只在选中这个主题时出现。
- **「05 主题排序」**：按住名称拖动排序，取消方框即可隐藏不用的主题；出厂顺序调整为编辑排版、透明书封、瑞士网格、像素、编辑排版-横、编辑排版-横-逆、液态玻璃，原「05 歌词」顺延为 06。
- **快捷面板「轮换主题」**：可勾选参与轮换的主题，点击进行轮换主题，同时发送toast通知。
- **锁屏天气可选「无」**：不画天气，也不再从原厂桌面组件或天气软件取数。
- **「模块设置 → 开机自启」**：开机后叫醒墨控的配置进程，默认开启；叫醒用的是无界面入口，不会弹出墨控首页。
- **「系统增强 → 01 待机与联网 → 亮屏时间」**：接管系统「设置 → 显示 → 休眠」，可选 1 分钟 / 2 分钟 / 5 分钟 / 10 分钟 / 30 分钟 / 永不 / 系统默认，也能自己填 1–999 分钟。写的是 `Settings.System.screen_off_timeout`，改完立即生效，也能用外部调用 `--es screen` 调。
- **「系统增强 → 07 备份 → 导入与导出设置」**：导出把墨控的设置写成一份文本，导入时先按配置格式严格校验、报「多少项设置 / 多少项开启 / 与当前相比多少处会变」，确认后整份替换并立即生效。只含功能开关与取值，不含提示时长、语言、列表顺序、书封图、字体与系统设置快照。

### 修复

- **开机后没打开过墨控时，翻页动画与全刷扫过不生效**：这台机器的进程管控不允许系统进程拉起墨控的配置服务，系统界面与系统服务读到的一直是「全部关闭」的设置快照；锁屏、快捷面板这些应用内的功能看着正常，只有跑在系统进程里的动画按原厂瞬切。现在后端在开机后自动叫醒配置进程，运行中这个进程被清理掉也会补回来；用户解锁前的那一段时间同样有效。
- **「WLAN 休眠策略」选「仅充电保持 / 永不保持」时，息屏断网后亮屏不恢复 WLAN**：原来按背光亮度判断息屏，这台机器把前光关到 0 时亮屏读到的也是 0，于是亮屏被当成息屏、关掉 WiFi 后再也开不回来。现在改为用系统的唤醒状态复核，恢复时还要确认网卡真的回来才清标记，失败就持续重试。
- 「待机与联网」的外部调用增加透明页入口，失败原因写进 logcat，方便排查。

### 变更

- **「系统增强」小节顺序调整**为 01 待机与联网 → 02 稳定性 → 03 刷新行为 → 04 安全 → 05 控制中心 → 06 导航栏 → 07 备份。
- **「模块设置」布局收紧凑**：语言 / Language、提示时长改成「标题 + 右侧小按钮」，与下面的开关行对齐。
- **「后台任务」改成开关**：开启＝最近任务列表里不显示墨控，关掉立刻恢复；位置在「开机自启」上方。
- 亮屏时间的详情页只留开关与档位，不再铺「开启前后」「需要知道」两段说明。
- 「书封选择」说明精简；锁屏主题的名称与默认顺序调整。

## 使用注意

- 本版后端有变化：**APK 与后端模块必须来自同一次构建、同批重装并完整重启一次**。新增配置项 `module.autostart`、`sys.screen.timeout`、`sys.config`，若只装新 APK 配旧模块，会因后端不认识这些键报「配置无效」或让 `ready=0`。
- 亮屏时间的档位由「秒」改成「分钟」：旧配置里的 `1800` 会自动折算成 30 分钟，不用手动改。
- 「开机自启」默认开启。关掉后，每次开机需自己打开一次墨控，否则翻页动画与全刷扫过仍会按原厂瞬切运行。
- 主题排序、隐藏状态与轮换范围是界面偏好，只影响本机显示顺序，不改变主题本身；导入导出设置也不含这些偏好。
