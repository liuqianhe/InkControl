# 墨控 InkControl 0.2.9-r30（versionCode 30）

## 更新内容

### 修复

- **开机一段时间（约半小时）后「全刷扫过」与「翻页动画」突然一起失效**：显示后端曾把一次「输入缓冲暂时不可预留」的单帧冲突当成永久 GPU 故障，置位后整个开机周期不再恢复；两条动画都走 GPU 波形路径，于是同时停摆，期间在墨控里切换开关或使用快捷面板都无法救回。现在这类冲突只回退当前帧、下一帧继续正常出图，其它真正的 GPU 导入/渲染错误仍按原样降级。
- **「GPU 显示后端」状态不再误报正常**：新增 `gpu_failed` 状态，出现真正的 GPU 致命降级时，运行状态与依赖它的动画项会明确显示原因；`inkctl status` 的 `GPU_BEGIN` 段同步输出该字段。

## 使用注意

- 本版改了原生显示后端：**APK 与后端模块必须来自同一次构建、同批重装并完整重启一次**，不要拿新 APK 配旧模块。
- 若升级后仍出现动画不生效，先看「运行状态 → GPU 显示后端」是否提示已降级；真降级时只能完整重启恢复，单纯切换开关无效。
- 本版未改功能开关与配置格式，升级不会改动您现有的开关取值。
