# 墨控 InkControl 0.2.1-r18

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布。本版在 0.2.0-r18 基础上重做锁屏「拓展显示」、新增系统应用卸载/还原入口、放大功能列表的分区小标题、重排瑞士网格版式，并把构建输出从 613 MiB 压到 169 MiB。**72 个增强全部默认关闭**（「设备状态」的四项显示开关除外，它们默认开启）。

版本号按仓库规则升为 0.2.1-r18：本版含配置键删除（`lock.ext.*` 四项合一后又按新语义恢复为四个显示开关）与新的后端命令，必须新版本，不覆盖 r18 的 Release。

## 锁屏「拓展显示」

- 「锁屏-通知」改名为「拓展显示」，由原先四个逐项开关精简为**两个总开关**：`lock.notify`（显示通知）与 `lock.ext`（显示设备状态）。
- 两者**严格二选一互斥**：开一个自动关另一个，互斥实现只在 `MainActivity.change` 一处，列表开关与详情页按钮走同一条路径；关对方时沿用其现值（`lock.notify.value=system|wechat`）。
- 设备状态条占原通知条位置（逻辑 y 613、高 42），显示**无线网络、蓝牙、声音模式、飞行模式**四项，取值实时读 WifiManager、BluetoothAdapter、`AIRPLANE_MODE_ON`、`getRingerMode()`。
- 图标用矢量 Path 现画（16×16 逻辑框：三段同心弧+圆点、卢恩字母 Bjarkan、实心喇叭+声波、俯视飞机），**不引外部图片**——墨水屏只有黑白，矢量在 2 倍放大下仍是硬边，也不必为第三方图标库背许可证与体积。
- 对齐按「墨迹」而不是方框：四个图标的墨迹纵向范围各不相同（wifi 天生扁、飞机最高），逐个等比缩放到同一墨迹高度并把墨迹中心压到文字视觉中线（基线上方 5px），四格看上去才是齐的。状态文字统一 13sp 加粗，声音项显示「有声」/「静音」。
- 实心图标（声音、飞行）目标墨迹高度单独提到 12.8 / 13.2：按墨迹等高归一后，实心图形比同高的细线图形视觉重量小，等重反而显小。
- 图标形状按 1-bit 量化效果定了三条硬约束：喇叭的声波弧必须画在正右半圆（`arc` 起始角 -45°，原来固定 225° 会画到喇叭头顶上）、飞机翼展要明显大于机身长（15 × 12.2，比例低于 1.15 就退化成十字）、平尾只有翼展一半宽。
- 状态条**会自动在单行与 2×2 之间切换**：竖版 312 宽单行四格（每格 78）；横版右下只有 155 宽、单格 38.75 装不下「图标 + 静音」，自动降级成 2×2，同列的图标左沿与文字左沿对齐（先按该列最宽项拼一行再整体居中），两行才不会错开。
- 旧配置 `lock.notify.value=ext` 自动迁移为 `lock.notify=0` + `lock.ext=1`；单值时代的 `lock.ext.value=default` 读成 `auto`。

## 锁屏「设备状态」：显示哪几项、画成什么样

- 「拓展显示」这一节现在只有三行：**显示通知**（开关）、**显示设备状态**（开关）、**显示信息修改**（无开关，点进去改）。原先并排铺开的四个显示开关收进「显示信息修改」一页，列表里不再出现四行小开关。
- 「显示信息修改」是纯页面项（`FeatureCatalog` 里取值写作 `@panel`，配置值恒为空串）：它自己不是开关，进去逐项开关的是 `lock.ext.*`。页首给出「N / 4 项显示 · 文字版」的汇总，下面是四行只带开关的行（点行不跳页，免得从四项详情返回时跳出「收纳」回到分类列表），末尾一个按钮跳去「显示设备状态」选图标版／文字版。
- 分类卡上的「已开启/总数」把这四项照旧算进「锁屏」（`Guide.Category.nested`）：它们仍在配置里、仍是可关的开关，只是换了入口，「锁屏」还是 16 项。
- 新增四个**显示开关**：`lock.ext.wifi` / `.bt` / `.audio` / `.airplane`，分别控制设备状态条里出现哪几项。关掉的项不占位，其余各项重新均分宽度（四项单行、三项两列上二下一、两项竖排）。这四个开关是**默认开启**的（`FeatureDefinition.defaultOn`：配置里没有这个键就按显示处理），所以老用户升级后四项仍在，之后各自关掉的才记住。
- `lock.ext` 从单值开关变为三选一：**跟随样式**（`auto`，默认）/ **图标版**（`icon`）/ **文字版**（`text`）。`auto` 时编辑排版与横版用图标，瑞士网格用文字——各样式保持原有观感。
- 文字版画成 `无线|开`：类型名与状态值**同为 13sp 加粗**、同一条基线，中间一条 1px 实心竖线（不用字形「|」，1-bit 下那根线粗细随字号变、还带侧边距）。原来瑞士网格是「类型 10sp + 状态 15sp」，一大一小既不像一组、也看不出是同一条视觉中线。
- 降级规则改为按项数通用的两列布局：任一项量不下就换两列、行数取 `ceil(n/2)`、按行优先填。原实现里 `n < 4` 会被强行塞进单行，三项时单格只有 51.7 宽，触发「极窄格子兜底」把类型名整个丢掉，只剩「开 关 开」。

## 锁屏「设备状态」在四套样式里的位置

- **编辑排版（竖版）**：倒数日下方那一块（y 613、高 42），单行四项。
- **编辑排版-横 / 编辑排版-横-逆**：右下角原通知框位置。框从 x605 / 宽 95 左移到 **x545 / 宽 155**（右缘仍与倒数日框对齐，与电量之间留出 5px），高度 40 → 48、框顶 280 → 272（框底 320 压在天气行字身顶 323 之上），电量行右界相应从 600 收到 540。逆版与正版共用同一份 `editorialLand()`，镜像由 canvas 旋转 180° 处理，无需另写。
- **像素**：先是在电池窗口**正下方另起一块**（沿用 `window()` 的老式窗口，2px 边框 + 4px 实心投影）塞四项，靠「图标在上、ON / OFF 在下」压缩宽度——该样式整体是英文标牌（CLOCK / NOW PLAYING / SLIDE TO UNLOCK），不混中文。本版末又把下半部整体重排为 **格言 → 电量 → 倒数日 → 通知/设备状态** 四块，见下节。
- **瑞士网格**：底部数据行正上方新增一条「通知带 / 设备状态带」——1px 分隔线 + 一行数据。显示通知时是「通知｜3 条」：类型 13sp、条数 26sp 黑体，两者**按墨迹中线对齐**且紧靠在一起（原来标签 10sp 贴左沿、条数 28sp 贴右沿，隔了三百像素，既远又不在一根视觉轴上）。显示设备状态时按 74+8 的四格网格排「无线|开」这类文字标牌，类型与状态同字号同基线、中间 1px 竖线；该样式通篇没有图标语汇，所以只用文字版。带子位置跟随格言块底部下移，钳在 578–604，始终与底部数据行成组。
- **液态玻璃**：底部是单行紧凑文本位，放不下四项，本版未适配，仍按通知位显示。

## 像素（竖版）版式：格言 → 电量 → 倒数日 → 通知/设备状态

- **为什么要重排**：原来通知数与电量同挤一行右端，设备状态块只能挂在电量正下方，读起来像「电量的附注」；而通知与设备状态本就是同一个位置的两个互斥总开关。现在电量独占一块，通知与设备状态**共用最后一块**：同高 58、标题分别是 `NOTIFY` / `STATUS`，来回切总开关时整摞块不会上下跳。
- **块高与间距**：电量 48、倒数日 80（无倒数日时整块不画）、状态槽 58（通知与设备状态都不显示时整块不画）。间距按 `(H-58-12-top-stack)/块数` 在 **12–22** 之间取值——最坏情形（格言 3 行 + 曲名 + 进度条、倒数日 3 组）仍停在 y 628，离底部解锁框（y 662）还有 34，绝不会压框。
- **电量块**：电池图标 scale 3（墨迹 24 高，中线压在块中线），内腔按电量从左填充、宽度取 3 的整数倍以落在物理像素上；百分比提到 **u=2.5**（一格 5 物理像素）撑起这块的视觉重量；充电时右端补一个 u=1 的 `CHARGING`，不充电就留白，不塞无意义装饰。
- **倒数日块**：`COUNTDOWN` 标题下每列「事项名 / N DAYS」，列宽分配与竖版一致（1 组居中、2 组 1/4 与 3/4、3 组 1/6 3/6 5/6）。天数是主要信息，走 5×7 点阵（u=1.5，1-bit 下比黑体干净），**已过用负号**（`-3 DAYS`）；事项名是中文，只能交给无抗锯齿黑体 16sp，超长按列宽横向压缩，不串邻列；没填事项时只画天数并在内容区里居中。
- **通知/设备状态块**：设备状态沿用四项「图标（墨迹 11 高）/ ON|OFF（u=1.5）」，比原来的 13 收小一档——有了标题栏，内容区只剩 32 高；通知则是 `NOTIFY` + 图标 scale 2 + 数字 u=2.5 + 中文来源名（`通知` / `微信`，那是数据不是标签，不译成英文）。

## 瑞士网格（竖版）版式调整

- **两行大时间的行距**：行距不能靠字形的偶然形状——「00」「20」看着松是因为 0 是圆弧、2 是斜肩，换成「11」「18」就会觉得贴在一起。196sp 的字墨迹约 141 高（数字没有降部，墨迹正好落在基线上），按这个量：字号收到 184sp、基线 188 / 392，墨迹落在 56–188 与 260–392，**间隙 72**（设备像素 144，原来只有 45），上沿离表头 10、下沿离分隔线 8。上机用「01 / 11」这种最难的组合复核过。
- **底部数据行改为三格**：电量 / 第几周 / **第几天**，三格同一套「大号数字 + 下方小字标签」排版。通知数已单独成带，不再占这一行的第三格（原来隐藏通知时只剩两格，格位会左右跳）。天数取的是「编辑排版 / 编辑排版-横」表头「第 N 日」同一个 `Calendar.DAY_OF_YEAR`，只是这里按「第几周」的版式排。
- 天气块整体上移 11（411 → 400）、格言块 517 → 500；有天气时格言全文收紧到 2 行，保证不压到通知带的分隔线。

## 系统应用卸载/还原

- 首页新增独立分类「系统应用卸载/还原」，排在「系统增强」之前，独立页面不走功能列表。
- 预制两项：`com.hmct.updater`（系统更新）、`com.tencent.android.location`（腾讯位置服务）。后端新增 `inkctl sysapp state|remove|restore`，包名双重正则校验，只对 user 0 卸载；`pm install-existing` 还原后仍是系统应用身份，系统分区 APK 不会被删。

## 界面

- 「大功能」内各功能列表的分区小标题（「样式」「拓展显示」「倒数日」「触发方式」「节奏」等）由 14sp 普通字重放大到 **21sp 加粗**，相对页标题 26sp、功能名 17sp、说明 13sp 形成清晰层级。
- 「自定义锁屏」页的**效果大图移到样式列表之后**（「需要知道」之前）：那一页真正的选项是带缩略图的样式列表，大图放上面会先占一屏。大图与缩略图的样张同时跟随「显示设备状态」——开着时画状态条而不是通知框，避免出现「开关开了但预览还是通知」的错觉。
- 大功能排序新增分类不再一律追加到末尾：保存顺序里没有的分类插到默认顺序中它前一个已排好分类之后。

## 开发工具

- 新增 `tools/IconPreview.java`：用与 `LockCanvas.drawIcon` 相同的 16 空间坐标绘制四个图标，再按「面板 2 倍 + 1-bit 阈值」二值化输出，3 秒就能判断图标在墨水屏上是否可辨，不必每改一处形状就装一次机器。

## 构建与产物

- 逐段中间文件从 `out/<name>/work/` 移到 `out/.work/<name>/`，**构建前后各清一次**：即使收尾清理失败，下一次构建开头也会整体清空，不再每个版本攒一份 13 MiB 的 `work/`。
- 用完即弃的中间产物立刻释放（`module/`、`classes/`、`classes.jar`、`unsigned.apk`、`normalized.apk`），`--keep-intermediates` 时全部保留。
- 新增 `--clean`（只清理不构建）、`--keep-builds N`（产物目录只留最近 N 个，默认 3）、`--cache-budget M`（构建缓存上限，默认 160 MiB，按「最久没命中」淘汰；命中会刷新时间戳）。
- 实测：`out/` 由 613 MiB 降到 169 MiB（34 个产物目录 → 3 个，缓存 250 MiB → 159 MiB），单个产物目录只留 APK 2.10 MiB + 后端 ZIP 1.03 MiB + 清单/证书/校验和。

## 版本与文档

- App 版本号 0.2.0-r18 → **0.2.1-r18**（versionCode 仍为 18），后端模块与 `ic_ready` 版本校验同步。

## 验收范围

第二轮（设备状态开关化 + 瑞士网格排版）本机装机验证：首页统计由 68 项变 **72 项**、「锁屏」由 9/12 变 **9/16**（四个显示开关已进入列表）；锁屏送屏位图逐一核对——瑞士网格「01 / 11」两行时间间隙明显、设备状态带为「无线|开」四格且同字号、通知带为「通知 0 条」且标签与条数中线齐平；编辑排版竖版图标版四格、文字版「无线|开」四格均正常；编辑排版-横在四项时为两列 2×2、关掉「声音」后变为上二下一且不丢类型名；`lock.ext.value=default`（单值时代的老配置）读成 `auto`，解析无异常。电脑端 `CoreTest`（1129 项）、`GeometryTest`、`GuideTest`（649 项）、`TextCatalogTest`（2748 项）全过。

首轮装机验证：`sys.inkcontrol.ready=1`、`helper_loaded=true`、`gpu_errors=0`；锁屏送屏位图四项图标与状态文字基线齐平、图标墨迹居中；互斥双向切换后两处 `configuration.txt` 同步为 `lock.notify=0`/`lock.ext=1`。五套样式逐一上机确认：编辑排版竖版单行四项、编辑排版-横与横-逆 2×2、像素在电池下方独立一块、瑞士网格通知带与设备状态带各自出图且三格数据行不重排；「自定义锁屏」页大图已位于样式列表之后，且预览里画的是状态条而不是通知框。云端回归、面板、温区、功耗与长稳仍待独立验收。
